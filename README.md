# bitflowcl/.github

Archivos por defecto de la organización. GitHub los aplica a cada repo de
`bitflowcl` que no tenga su propia versión, desde que llegan a `main`.

| Archivo | Para qué |
|---|---|
| `profile/README.md` | Portada pública de la organización |
| `pull_request_template.md` | Plantilla de la descripción de un PR |
| `ISSUE_TEMPLATE/config.yml` | Opciones al abrir un issue: Linear, seguridad o en blanco |
| `CONTRIBUTING.md` | Ramas, commits, PRs, revisor automático y merge |
| `SECURITY.md` | Cómo reportar una vulnerabilidad |
| `workflow-templates/` | Workflows sugeridos en la pestaña Actions de cada repo |

Este repo es público porque GitHub lo exige para aplicar los archivos por
defecto: lo que se agregue aquí no lleva clientes, hosts, IPs, secretos ni
detalles de infraestructura.
